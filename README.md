# OddMoney — preview build artifact

This repository contains **only the compiled static output** of the OddMoney
MVP, published so the preview has a public URL. The source, data records and
project documentation live in the private `OddMoney` repository.

**Preview:** https://bol-ship-it.github.io/oddmoney-preview/

Every page is served `noindex, nofollow` and `robots.txt` disallows crawling —
a temporary host must not compete with the real domain in search once one
exists.

Do not edit anything here. It is overwritten by `npm run publish:preview`
in the source repository.
